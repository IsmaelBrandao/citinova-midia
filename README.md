# Mídia da Rede viva de inovação — CITINOVA

Arquivos pesados da exposição *Rede viva de inovação*, servidos pelo GitHub
Pages para chegar perto do totem, em Fortaleza.

- `citinclusiva-libras-v2/` — o vídeo do CITInclusiva com intérprete de Libras,
  em HLS (fMP4, pedaços de até 8 s). É a versão de 6,8 Mbps cortada sem
  recompressão: o hash de cada pacote de vídeo e de áudio é igual ao do MP4.

Nenhum arquivo é alterado depois de publicado. O totem guarda os pedaços que
já tocou, e trocar um arquivo sob o mesmo nome misturaria duas versões na
tela. Uma versão nova vai numa pasta nova (`-v3`, `-v4`), e o site passa a
apontar para ela.
